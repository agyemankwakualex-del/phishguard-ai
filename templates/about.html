PhishGuard AI

PhishGuard AI is a final-year cyber security project at Accra Technical University. It scores one email at a time, from a paste or from a read-only Gmail message, and keeps the verdict in your history.

How a scan works

  1. Input. You paste a sender, subject, and body, or PhishGuard reads one Gmail message with the gmail.readonly scope. A Gmail body is cut to 100,000 characters before the scan. A paste is the text you submit.
  2. Links. The first 5 unique http and https links are taken from that full text, in the order they appear. A repeated link is kept once, at its first position.
  3. VirusTotal. When a VirusTotal key is set and at least one link was found, each of those links is checked. A malicious report is High, a suspicious report is Medium, and a clean report is Low. No key, a link VirusTotal does not know, a rate limit, or a failed lookup is Unknown.
  4. AI. When AI is on and a Groq key is set, openai/gpt-oss-20b reads the sender, the subject, and the first {{ '{:,}'.format(ai_body_limit) }} characters of the body. The request asks Groq for a JSON object and tells the model when VirusTotal found malicious links.
  5. Rules. When AI is off, the Groq key is missing, or the model call fails, built-in rules score urgency and password wording in the full subject and body, plus any malicious VirusTotal hits. The rules do not run when the model returns a result.
  6. Score. The scan returns one level, High, Medium, or Low, and a score from 0 to 100. A malicious VirusTotal hit sets the level to High. On an AI result the score is raised to at least 90. On a rules result that hit adds 100 points, and the score is capped at 100. The engine name is AI or Rules, and it includes VirusTotal when a key was set and links were found.
  7. History. The sender, subject, level, score, reasons, and engine are saved. The email body is not saved.

Tech stack

Flask SQLAlchemy Supabase Postgres Vercel Groq VirusTotal Gmail API (gmail.readonly)

The deployed app uses Supabase Postgres through DATABASE_URL. A local run with that variable unset uses SQLite. Gmail also requests userinfo.email so the connected address can be shown.

Security and privacy

  • ✅
    CSRF

    State-changing forms send a CSRF token. A post without it is rejected.

  • ✅
    POST-only logout

    Logout is a POST form with the CSRF token. Opening logout with GET is rejected.

  • ✅
    Rate limiting

    Failed logins are limited to 5 per minute for the email and 5 per minute for the IP. Registration is limited to 5 posts per minute for the IP.

  • ✅
    8-character passwords

    Registration and password change reject a password shorter than 8 characters. The forms set the same minimum.

  • ✅
    Initials, no external avatar

    The account menu shows initials from the username. It does not request an avatar from another site.

  • ✅
    Read-only Gmail

    The Gmail scope is gmail.readonly. PhishGuard reads messages. It does not modify, send, or delete them.

  • ✅
    Gmail tokens encrypted at rest

    Access and refresh tokens are Fernet-encrypted with SHA-256 of SECRET_KEY before they are stored. A value that cannot be decrypted is treated as disconnected. The Gmail address stays readable.

  • ✅
    OAuth state check

    Google sign-in stores a random state in the session and sends it to Google. If the callback state is missing or does not match, PhishGuard stops before exchanging the code.

  • ✅
    Disconnect revokes the token

    Disconnect asks Google to revoke the refresh token, or the access token if there is no refresh token, and then clears the stored Gmail fields.

  • ✅
    History omits the body

    Saved rows keep the sender, subject, score, reasons, and engine. They do not keep the email body.

Limitations

  • ⚠️
    The model can be wrong

    Groq output is not a guarantee. A failed model call falls back to the built-in rules.

  • ⚠️
    The score is not a measured accuracy

    0 to 100 is the model number, or the rule total. It is not a tested accuracy percentage.

  • ⚠️
    VirusTotal can return Unknown

    Unknown means the link was not checked, VirusTotal has no report, the lookup failed, or VirusTotal rate limited the request.
